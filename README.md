# Gmail 重複メール検出・自動ゴミ箱移動

同じ日に、同じ件名・同じ本文・同じ送信者で届いたメールを重複とみなし、
最も古い1通を残して残りを自動でゴミ箱へ移動する Google Apps Script (GAS) です。

## 仕組み

- `src/Code.gs` の `findAndTrashDuplicateEmails()` が、直近 `CONFIG.LOOKBACK_DAYS` 日間の
  受信トレイを検索します。
- メールごとに「日付（yyyy-MM-dd）＋件名（正規化済み）＋本文のハッシュ値＋送信者」を
  キーとしてグループ化し、同じキーが2件以上あれば重複と判定します。
- 重複グループの中で最も古い1通だけを残し、残りをゴミ箱へ移動します。
- 重複メッセージが他の非重複メッセージと同じスレッドに属している場合は、
  スレッドごとの削除による巻き添えを避けるため自動処理せず、ログに
  「手動確認要」として記録します。

## セットアップ手順

1. [script.google.com](https://script.google.com/) で新しい Apps Script プロジェクトを作成する
   （または `clasp create` で作成し、このリポジトリを push する）。
2. `appsscript.json` の内容をプロジェクトのマニフェストに反映する。
3. `src/Code.gs` の内容をスクリプトエディタにコピーする。
4. まずは安全確認のため `CONFIG.DRY_RUN = true` にした状態で
   `findAndTrashDuplicateEmails` を手動実行し、初回の権限承認を行う。
5. 実行ログ（表示 > ログ）で、ゴミ箱へ移動される予定のメール一覧を確認する。
   問題なければ `CONFIG.DRY_RUN = false` に戻す。
6. `createDailyTrigger` を一度だけ手動実行すると、毎日 6:00（`Asia/Tokyo`）に
   自動実行されるトリガーが設置される。

## 設定項目（`CONFIG`）

| 項目 | 説明 |
| --- | --- |
| `LOOKBACK_DAYS` | 何日前までのメールを検索対象にするか |
| `SEARCH_QUERY` | Gmail 検索演算子で対象を絞り込む（例: `-in:chats` で除外） |
| `DRY_RUN` | `true` の場合、削除せずログ出力のみ行う |
| `REQUIRE_SAME_SENDER` | 同一送信者からのメールのみ重複とみなすか |
| `NOTIFY_EMAIL` | 実行結果をメールで通知したい場合に指定 |
| `PAGE_SIZE` / `MAX_THREADS` | 検索時のページングと安全上限 |

## 注意事項

- Apps Script の `GmailMessage.moveToTrash()` はメッセージが属する
  スレッド全体をゴミ箱へ移動する仕様のため、このスクリプトは
  重複メッセージが単独スレッド（1メッセージのみ）である場合にのみ
  自動でゴミ箱へ移動します。スレッドに他のやり取りが含まれる場合は
  安全のためスキップされ、ログに記録されます。
- 誤検知が心配な場合は、まず `DRY_RUN = true` で数日運用し、
  ログの内容を確認してから自動削除を有効にすることを推奨します。
- ゴミ箱に移動したメールは Gmail 側の設定（通常30日）で自動的に完全削除されます。
  誤って削除した場合はゴミ箱から元に戻せます。
